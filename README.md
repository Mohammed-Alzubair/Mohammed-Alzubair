## 👨‍💻 About Me

I learn by building complete things. Every subject I work on ends in a finished, documented project, and I care about clear structure, precise code, and documentation that lets anyone run what I made.

My focus is on the parts of software that applications depend on: how data is stored and queried, how memory and data structures behave, and how programs communicate with databases and networks. That is why I build the foundations by hand, such as linked lists, stacks, database schemas, and scene hierarchies, instead of relying on shortcuts.

Outside the classroom, technology is still my main interest: I build personal projects and explore AI tools. I work in Arabic, English, and Chinese, and I'm used to working in teams of five: dividing responsibilities and combining individual parts into one working system.
